## Descripción

Script en PowerShell (info-sistema.ps1) que obtiene:

1. Versión de PowerShell
2. Política de ejecución (permisividad)
3. Edición del sistema operativo
4. Información completa de la PC con el comando systeminfo del símbolo del sistema

## Uso

Ejecutar en PowerShell: .\info-sistema.ps1

El archivo salida.txt contiene el resultado de una ejecución.
